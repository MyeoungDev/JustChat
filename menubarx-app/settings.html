Window positions

Save the current size and position, then recall it with Option+Command+1–5. Hold Shift while pressing a number to save that slot. Option+Command+0 restores the default layout.

Site permissions

Notifications, location, camera, and microphone start blocked. A site must ask and you must approve it. Camera and microphone access also require macOS approval. Screen sharing remains blocked.

Shortcuts

Select a shortcut and press the new key combination. Clear removes an optional shortcut. Global shortcuts work while another app is active.
